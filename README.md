## 🚀 Featured Projects

### [MoodPlay — Instance-Guided Semantic Video Colorization](https://huggingface.co/stfnnnnnnn/moodplay/tree/fix%2Fcolor-bleeding)
An undergraduate thesis project exploring object-specific video colorization using conditional latent diffusion. Integrates Grounded SAM 2, CoTracker, XMem, three ControlNet branches, and trained LoRA style adapters to support consistent object colors and customizable visual styles.

**Role:** Lead Software Developer · System Architect · Project Manager

### [FlyRank AI — Early Content Decline Risk Prioritization](https://github.com/stfnnnnnnn/karl-mangahas-flyrank)
Applied machine learning research focused on identifying web pages at risk of future search-visibility decline. Involved historical feature engineering, model benchmarking, leakage-safe validation, and interpretable content-review recommendations using pseudonymized Google Search Console data.

**Role:** Machine Learning Intern · July–September 2026

### [VibeBoard — Student Productivity Platform](https://github.com/stfnnnnnnn/VibeBoard)
A full-stack student productivity application integrating academic planning, grade projections, context-aware task coordination, personal finance, and habit tracking. Includes Canvas LMS integration, authentication, persistent data storage, and automated synchronization.

**Tech Stack:** Next.js · React · TypeScript · MySQL

### [SIGNAL NO. 5 — Local AI Disaster Preparedness RPG](https://github.com/stfnnnnnnn/signal-no.5)
A household-personalized 8-bit RPG that teaches typhoon preparedness through interactive disaster scenarios. Combines deterministic simulation logic with locally running Qwen3-4B inference for contextual dialogue and personalized debriefs.

**Role:** Lead Backend Engineer · Project Manager

### AGAP — Angkop na Gamit, Angat na Paglilingkod
An energy intelligence concept developed for the NEXTGENPH 2026 Innovation Contest. The blueprint proposes service-aware energy monitoring, interactive 3D building visualization, and scenario-based recommendations to help government facilities conserve energy while preserving essential public services.

**Role:** Concept Developer · System Blueprint & Framework Lead
